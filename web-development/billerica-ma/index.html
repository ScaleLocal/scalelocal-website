FAQ

Common questions

Will the site actually load fast or is that marketing-speak?

Core Web Vitals are measurable. After launch we monitor PageSpeed Insights scores, Lighthouse, and real-user load times. You can check the numbers yourself anytime. Sub-two-second mobile load isn't a claim — it's a measurable target we hit.

What about plugins and themes &mdash; do you avoid them?

We avoid the heavy WordPress + theme + page-builder stack because it ships bloated code and is hard to keep fast. The static-first approach we use produces faster sites with less long-term maintenance debt. Some lightweight integrations (Google Business Profile, schema, analytics) are baked in cleanly.

Can the site grow with new services or new locations?

Yes — adding service pages, new town pages, or new content sections is straightforward in the stack we use. We do it on an ongoing basis as part of the monthly plan.

What if I already have a site? Do you migrate it or rebuild?

For most Billerica trades the existing site is built on an old WordPress theme that fights every modern best practice — we rebuild rather than try to patch it. The content migrates over, the old URLs get 301-redirected to the new ones, and search authority transfers cleanly.

Is the codebase portable?

Yes. If you ever want to move the site to your own hosting or a different vendor, the code goes with you. We don't run proprietary lock-in. The monthly relationship works because the work earns it.
